## いまの立ち位置

| 要素 | 状態 |
|------|------|
| 対応級 | 5・4・3・準2（オリジナル練習） |
| コンセプト | 無料・ブラウザ・登録なしで1問から |
| 習慣化 | ミッション／ストリーク等（ゲーミフィケーション Phase 1〜2） |
| 収益方針 | フリーミアム課金は採用しない → 級・弱点に沿った教材アフィリエイト |
| ブランド | えいごごはん。試験名は説明用。公式ではない |

**前提の切り替わり**

- 級を4つ揃えた＝成長エンジンができた、ではない。
- 次に足りないのは「機能」より **人が来る仕組み** と **来た人が戻る理由**。
- 競合（abceed・英検トレーニング・mikan・ネットドリル等）が多く、「英検練習できる」だけでは差がつきにくい。

**一言の戦略**

> 「無料で本番形式を毎日ちょっと」を、受験月の親子が必ず見つける場所にする。  
> 収益は、その延長で「次の教材」を紹介する。

## 優先順位（やることの順番）

### 1. 集客をプロダクトの本線にする（最優先）

ユーザーが増えないとき、ボトルネックはほぼ **認知・流入**。

| やること | 狙い |
|---------|------|
| SEOを「級×悩み」で取る | 親の検索は「英検4級 リスニング 勉強法」「3級 ライティング 何書けば」など。既存の guides / 級×パートを活かす |
| 保護者向けの入口を明確にする | 教材購入・継続判断は親。無料／非公式／オリジナルなどの安心材料を前面に |
| 受験シーズンに合わせた露出 | 年3回の英検前に「今週やるならこの順」系コンテンツ。作問よりコスパが良い |
| 口コミの導線 | 先生・塾の補助、親コミュニティ。「宿題代わりに使える無料サイト」は拡散しやすい |

**計測**

- GA4 は導入済み。次に見る指標例:
  - 流入経路
  - 級別セッション
  - 1問以上解いた率
  - 翌日再訪

仮説を増やす前に、上記を見てから次の一手を決める。

### 2. 「また使う」を尖らせる（定着）

無料で解けるサイトは多い。差がつくのは次のあたり。

| 方向 | 内容 | 備考 |
|------|------|------|
| 今日やることが一瞬で分かる | ミッションは既存。受験日までの計画まで伸ばす候補 | ゲーミフィケーション改善と接続 |
| 弱点が日本語で分かる | 親が見ても「リスニング第2部が弱い」と分かる | 保護者向け価値 |
| 本番前の通し練習 | 模擬の「本番っぽさ」 | 既存模擬の体験強化 |

ゲーミフィケーション Phase 3（マスコット等）より、**「合格までの道筋が見える」** を優先する。

### 3. 収益は「無料の延長」のまま厚くする

サブスクはコンセプト（小学生・無料で試せる）とずれやすい → 当面やらない。

| 順番 | 内容 |
|------|------|
| 1 | アフィリエイトを本気で回す（Amazon タグ本番・outbound クリック計測・級／弱点に合う具体商品・受験直前期の tip 強化） |
| 2 | トラフィックが増えてから、表示広告や保護者向け有料（週次レポート等）を検討 |
| 3 | B2B（教室・塾向け）は第二波。ユーザー数が増えてから |

**収益 ← 利用の深さ × 人数**。課金機能を先に作っても、人がいなければほぼゼロ。

詳細・実装状況は [affiliate_next_learning_specification.md](affiliate_next_learning_specification.md)。

### 4. コンテンツ拡張の順番

| 優先 | 内容 | 理由 |
|------|------|------|
| 高 | 既存4級（5・4・3・準2）の問題量・解説・弱点フィードバック | 来た人の満足度＝口コミ・再訪 |
| 高 | SEO／保護者導線／受験カレンダー連動 | 新規獲得 |
| 中 | ライティング自己チェックの強化 | 3級以降の差別化。[writing_check_roadmap.md](writing_check_roadmap.md) |
| 低 | 2級・準1・TOEIC | ターゲットが変わり作問コストも跳ねる。流入と定着が動いてから |

「いろんなユーザー」は全級対応で取るより、まず **5〜準2の親子** で深く取る。

## 直近アクション（小さく始める）

1. GA4で流入経路・級別セッション・1問以上解いた率・翌日再訪を見る
2. 検索意図に合う記事を数本（例: 3級ライティング書き方、4級リスニング勉強法、受験1週間前やること）→ サイト内練習へ誘導
3. アフィリエイトのタグ＋クリック計測を本番で効かせる
4. 保護者向けに「子どもにどう使わせるか」を1画面で説明

---

## やらない／後回し（当面）

- 級の上位拡張（2級以上）を成長の主手段にすること
- フリーミアム課金を先に作ること
- ゲーミフィケーションの見た目拡張を集客より優先すること
- 押し売りバナーやダイアログでの教材誘導（アフィリエイト仕様の方針どおり）

## 判断のためのメモ

数字が分かれば、次の四半期は次のどれに振るかを決めやすくなる。

| 寄せ先 | 向いているサイン |
|--------|------------------|
| SEO寄せ | オーガニック流入がほぼ無い／検索クエリが弱い |
| 口コミ寄せ | 解いている人はいるが新規が伸びない |
| 収益寄せ | セッションと再訪はあるが outbound／教材誘導が弱い |

個人開発の時間制約がある場合は、**集客 1 本＋アフィリエイト計測 1 本** を同時に走らせ、作問は既存級の穴埋めに限定するのが現実的。
