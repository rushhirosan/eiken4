## オーディエンス（級で相手が変わる）

準2がある以上、「子ども向けサイト」一色にはしない。サイトは両方受け、**外への一言と集客チャネルだけ級で分ける**。  
英検に年齢制限はない。下表は「いちばん多いパターン」であり、大人ゼロの意味ではない。

| 級 | 主な利用者 | 集客の相手 | 刺さる言い方 |
|----|-----------|------------|--------------|
| 5・4 | 小学生〜中1が中心。大人は少数（英語ほぼ初めて／ブランク／子どもと一緒） | **主に保護者**が探す・決める。やり直しの大人が自分で来ることもある | 安心・宿題代わり・1問から・無料（小学生専用トーンには振り切らない） |
| 3 | 中学生中心。やり直しの大人もいる | 親＋本人が半々 | 受験前の通し・ライティングの型 |
| 準2 | 中3〜高・社会人 | **本人**が検索・継続 | スキマ時間・本番形式・登録なしで試せる |

**伸ばし方の使い分け**

- **人数・口コミ**: 5〜3 の親子・学校需要の方が動きやすい（宿題・受験シーズン）。5・4の大人を主戦場にはしない（母数が小さい）
- **SEOの明確さ**: 準2本人は検索意図がはっきりしている（「準2 ライティング」「準2 リスニング 対策」）のでガイドと相性が良い
- **やってはいけないこと**: 最初から「子どもも大人も全方位マーケ」でメッセージをぼやかすこと／LPを小学生専用にしてやり直し層を遠ざけること

共通の売り（級を問わず）: **無料・本番形式・1問から・オリジナル・公式ではない**。

## いまの立ち位置

| 要素 | 状態 |
|------|------|
| 対応級 | ✅ 5・4・3・準2（オリジナル練習） |
| コンセプト | ✅ 無料・ブラウザ・登録なしで1問から |
| 習慣化 | ✅ ミッション／ストリーク等（ゲーミフィケーション Phase 1〜2） |
| 収益方針 | ✅ フリーミアム課金は採用しない → 級・弱点に沿った教材アフィリエイト |
| ブランド | ✅ えいごごはん。試験名は説明用。公式ではない |

**前提の切り替わり**

- 級を4つ揃えた＝成長エンジンができた、ではない。
- 次に足りないのは「機能」より **人が来る仕組み** と **来た人が戻る理由**。
- 競合（abceed・英検トレーニング・mikan・ネットドリル等）が多く、「英検練習できる」だけでは差がつきにくい。

**一言の戦略**

> 「無料で本番形式を毎日ちょっと」を、受験月に探す人（保護者＋準2本人）が見つける場所にする。  
> 収益は、その延長で「次の教材」を紹介する。

## 優先順位（やることの順番）

### 1. 集客をプロダクトの本線にする（最優先）

ユーザーが増えないとき、ボトルネックはほぼ **認知・流入**。  
やり方の本体は「広告」ではなく **見つかる場所に置く**（SEO・口コミ・受験前の露出）。

| 状態 | やること | 狙い / 現状メモ |
|------|---------|----------------|
| ✅ | SEOを「級×悩み」で取る（土台） | `guides`・`guide_topics`（級×パート）・`exam-one-week-before` 公開済み。準2ガイドも含む |
| ⬜ | Search Console で表示クエリを見る | どの級・どの悩みが検索されているかの入力。GA4とセット |
| 🔶 | 入口を級で出し分ける | 保護者向け「子どもへの使い方」＋準2本人向け「スキマで試す」をぼかさない。LPを子ども専用トーンに振り切らない |
| 🔶 | 受験シーズンに合わせた露出 | サイト内に「受験1週間前」あり。季節の外部発信（X / note 等）は未 |
| ⬜ | 口コミ・置いてもらう導線 | 親コミュニティ／先生・塾向け（5〜3）。準2は友人・同僚・SNSで「無料で試せる」一文 |

**チャネル別の現実的な振り方**

| チャネル | 向く相手 | メモ |
|----------|----------|------|
| SEO（既存ガイド強化） | 親＋準2本人 | 広告費ゼロ。順位は遅いが本筋。記事新規より既存→練習CTA |
| 口コミ・学校／塾 | 主に5〜3 | 「宿題代わりに1日3問」が強い |
| 受験前の短文発信 | 両方 | 年3回だけ頑張る |
| リスティング等の有料広告 | 後回し | 数字が出てから |

**計測**

| 状態 | 項目 |
|------|------|
| ✅ | GA4 埋め込み（`G-8WVRCJX26T`） |
| ⬜ | 流入経路を見る |
| ⬜ | 級別セッションを見る（準2比率も） |
| ⬜ | 1問以上解いた率を見る |
| ⬜ | 翌日再訪を見る |
| ⬜ | Search Console のクエリ・表示回数 |

仮説を増やす前に、上記を見てから次の一手を決める。準2セッションが思ったより多ければ、本人向けコピーと準2 SEO を厚くする。

### 2. 「また使う」を尖らせる（定着）

無料で解けるサイトは多い。差がつくのは次のあたり。

| 状態 | 方向 | 内容 | 備考 |
|------|------|------|------|
| ✅ | 今日やることが一瞬で分かる（基本） | デイリーミッション | 受験日までの計画は未 → ⬜ |
| 🔶 | 弱点が日本語で分かる | 進捗ページにカテゴリ別正答率あり | 親向け一言要約＋本人向け「次に解くカテゴリ」の両方に使える |
| 🔶 | 本番前の通し練習 | 模擬試験メニューあり | 「本番っぽさ」の体験強化は未 |

ゲーミフィケーション Phase 3（マスコット等）より、**「合格までの道筋が見える」** を優先する（Phase 3 は意図的に後回し ✅方針）。  
大人（準2）向けに子供っぽい演出を増やしすぎない。

### 3. 収益は「無料の延長」のまま厚くする

サブスクはコンセプト（無料で試せる）とずれやすい → 当面やらない（✅方針）。  
小学生前提の課金より、**級に合う教材アフィリエイト**の方が自然（準2本人にも教材導線は有効）。

| 状態 | 順番 | 内容 |
|------|------|------|
| 🔶 | 1 | アフィリエイトを本気で回す |
| ⬜ | 2 | トラフィックが増えてから、表示広告や保護者向け有料（週次レポート等）を検討 |
| ⬜ | 3 | B2B（教室・塾向け）は第二波。ユーザー数が増えてから |

**順番1の内訳**（詳細は [affiliate_next_learning_specification.md](affiliate_next_learning_specification.md)）

| 状態 | 項目 |
|------|------|
| ✅ | Phase A guides 埋め込み |
| ✅ | Phase B `/resources/` |
| ✅ | Phase C 回答結果 tip（週1） |
| ✅ | 本番 `SHOW_NEXT_LEARNING = True` |
| ⬜ | `AMAZON_ASSOCIATE_TAG` を Fly secrets に設定 |
| ⬜ | outbound click の GA 計測 |
| ⬜ | 級／弱点に合う具体商品（ASIN）。準2は本人が買う教材も候補 |
| ⬜ | 受験直前期の tip 強化 |

**収益 ← 利用の深さ × 人数**。課金機能を先に作っても、人がいなければほぼゼロ。

### 4. コンテンツ拡張の順番

| 状態 | 優先 | 内容 | 理由 / メモ |
|------|------|------|-------------|
| 🔶 | 高 | 既存4級（5・4・3・準2）の問題量・解説・弱点フィードバック | 公開済み。量・解説・弱点の継続改善は継続タスク |
| 🔶 | 高 | SEO／入口出し分け／受験カレンダー連動 | SEO 土台 ✅。親用・本人用コピーと季節露出は未 |
| 🔶 | 中 | ライティング自己チェックの強化 | Phase 1 ✅。3級・準2の差別化。[writing_check_roadmap.md](writing_check_roadmap.md) |
| ⬜ | 低 | 2級・準1・TOEIC | ターゲットが変わり作問コストも跳ねる。流入と定着が動いてから |

「いろんなユーザー」は全級対応で取るより、まず **いまの4級の中で、親（5〜3）と本人（準2）の両方を深く取る**。

## 判断のためのメモ

数字が分かれば、次の四半期は次のどれに振るかを決めやすくなる。

| 寄せ先 | 向いているサイン |
|--------|------------------|
| SEO寄せ | オーガニック流入がほぼ無い／検索クエリが弱い |
| 口コミ寄せ（親子） | 5〜3 は解いているが新規が伸びない |
| 本人寄せ（準2） | 準2セッションや「準2 ○○」クエリが無視できない比率 |
| 収益寄せ | セッションと再訪はあるが outbound／教材誘導が弱い |

個人開発の時間制約がある場合は、**計測 1 本（GA4＋Search Console）＋アフィリエイト計測 1 本** を同時に走らせ、コピー出し分けは短文から。作問は既存級の穴埋めに限定するのが現実的。
