## 4. オリジナル網羅チェック用メモ

- モノローグ内の**複数の数字・予定**から、質問が指す1点だけを取る練習が中心。
- 「すでに得意／昔やっていた」と「これから挑戦」の取り違えが典型ひっかけ。
