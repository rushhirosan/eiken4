## 4. オリジナル網羅チェック用メモ

- 配分を崩さない: **内容1 + イラスト2 + 自分2**。
- イラストは What is X doing? / What is X looking at? が定番（進行形）。
- パーソナルは Do you …? / Have you ever …? / What do you like …? / Can you …? / How do you …?。
