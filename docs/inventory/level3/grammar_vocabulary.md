## 5. オリジナル網羅チェック用メモ

- 文法は **現在完了・関係詞・不定詞／動名詞の型・比較・助動詞・時制（過去／過去進行）・too〜to / enough to** が厚い。
- 熟語は **前置詞コロケーション（look for / be interested in / be proud of 等）と会話定型（What’s the matter? / Would you like〜?）** が多い。
- 語彙は名詞（事故・面接・水族館など）と形容詞・動詞が混在。同一語の再出もある（accident など）。
- 公開オリジナルの `【ポイント】見出し` と本表の「聞いていること」列を突合するとギャップが見える。
