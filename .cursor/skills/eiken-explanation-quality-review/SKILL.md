# Explanation Quality Review

オリジナル問題の解説を、子供が一人で読んで分かる密度まで上げる。問題文・選択肢・正解は変えない（変える必要があるなら先に `eiken-question-quality-review`）。

## Inputs to confirm

- 級（`5` / `4` / `3`）
- カテゴリ
- 対象範囲（全件 or 番号レンジ）

対象は `data/questions/original/level{N}/`。公式由来 txt の解説をコピーしない。文体の参考にも公式解説は使わない。

## Review criteria

1. **懇切丁寧**: 初見の子供が、大人に聞かなくても先へ進めるか
2. **正解の根拠**: なぜそれが正解か、文中のどこ／どの意味か
3. **誤答の理由**: 主要な誤答それぞれが、なぜ合わないか
4. **級の言葉**: 日本語も英語用語も、その級の子供向けか
5. **学習の一手**: 次に似た問題が来たときの見方があるか
6. **定型の連発がないか**: 「正解は〜です」だけで終わっていないか

## Level bar

### 5級（丁寧寄り）

- まず正解語の意味。次に文全体のやさしい日本語
- 誤答は単語の意味を添えて「この文では使えない理由」を書く
- 文法用語（現在進行形、前置詞 など）は使わないか、使うなら直後に例で言い換える
- 漢字には必要ならひらがな

構成の目安:

1. 正解は「…」です。意味は「…」です
2. 文全体は「…」という意味です
3. ほかの選択肢: 「A（意味）」は〜なので合いません

### 4級

- 正解理由を先に。誤答はグループ化してよい（場所の答え／時の答え、など）
- 短い学習ポイントを1文（疑問詞に注目、など）

### 3級

- 根拠を本文・会話の該当箇所に結びつける
- ひっかけ（別の話者の情報、補足情報）を明示する
- 用語は最小限。使うなら例とセット

## Workflow

1. 対象の問題と解説を読む。
2. 短い・根拠なし・誤答未言及・難しすぎる日本語をリストする。
3. 問題フォーマットを崩さず【解説】（または【参考解答】）だけ直す。
4. 同級・同カテゴリの original 内で粒度をそろえる。
5. 改訂番号と、何が足りなかったかを短く返す。

## Do not

- 解説を長くするために公式の解説文を借りない
- 問題の英文を解説でほぼ全文英日対訳しすぎて、答えを丸暗記させるだけにしない（必要な範囲の対訳は可）
- 正解番号や選択肢本文を解説改訂のついでに変えない

## Output format

- 改訂した問題番号
- 変更前の課題（短く）
- 改訂方針（短く）

## Example requests

- 「5級文法のオリジナル解説を懇切丁寧にレビューして」
- 「今作った会話補充の解説だけ直して」
