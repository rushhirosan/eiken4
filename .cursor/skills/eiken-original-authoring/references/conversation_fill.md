# conversation_fill（会話補充）

ファイル: `conversation_questions.txt`  
コマンド: `register_conversation_fill_questions`  
空所に入る発話を4択で選ぶ。

## Template

```
問題1:
Girl : What time is the bus? Boy : ( )

選択肢1:
1. At eight.
2. It’s a book.
3. I’m hungry.
4. By bike.

【正解1】
1. At eight.

【解説1】
「バスは何時？」と時刻を聞いているので、「At eight.（8時です）」が自然です。
「It's a book.」はもの、「I'm hungry.」は気持ち、「By bike.」は行き方で、時刻の答えになりません。

---
```

## Rules

- 話者ラベルは `A :` / `B :` または `Girl :` / `Boy :` など。既存パーサは文面全体を取る
- 空所は発話の一部または発話全体の `( )`
- 誤答は「別の疑問詞に対する答え」など、よくある聞き違いにする（意味不明な英語は避ける）
- 選択肢は必ず4つ。重複テキスト禁止
- 5級: 短いやりとり。現行公開セットは20問（本番大問2は5問）
- 4級: 少し長い会話。誤答は聞き違い型。現行公開セットは20問（本番大問2は5問）
- 3級: 理由・経験・予定まで。4級と同じ場面の焼き直しにしない。現行公開セットは20問（本番大問2は5問）
- 準2級: 空所は文の途中の句。1会話は約65語。誤答は会話に出た別の事実。詳細は [pre2.md](pre2.md)
- 正解の人・場所・物は、空所より前の発話で一つに決まっている。直後の文や B の締めでは初めて出さない。直後は確認にする。場所を前後に分けない。似た物・似た人は、正解の側だけを前で名指しする。those / there の名詞は前にある。誤答がまだ正しく読めるなら、本文でその読みを閉じる。正本は作問スキルの「空所の論理（必須）」
- **行き方・距離・乗り物**（電車、家経由など）も空所前か正解句で決める。`another way` や待ち合わせ場所だけにしない
- **物の行き先を消さない**（会議室に入れない犬は、先に家へ、など）
- **誤答の質**: 本文否定のエコーだけで正解が残る／論外肢だけで消去法、は不可。半分正しい罠を残す。`too noisy` だけでは誤答を閉じない
- **正解が見えすぎない**: B の思い込みを空所前に置き、それを外す。材料を全部並べたあと `why don't you` だけ、は薄い
- **同型を並べない**: 隣で `ask X to …` や同じ順序パズルが続かない。骨格を散らす
- **自然なやりとり**: A の情報ダンプを避ける。応答は質問に噛み合う。空所を3発話目の A に固定しない（位置と話者を散らす）
- 正本の詳細は作問スキルの「空所の論理」「選択肢と会話の質」
