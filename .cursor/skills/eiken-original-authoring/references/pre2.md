# 準2級（level `pre2`）

3級の型を長くしただけでは準2級にならない。ここは 2025年度第2回・第3回・2026年度第1回の冊子で揃っていた枠。問題文はコピーしない。他級の表示・登録・進捗は変えない。

出力: `data/questions/original/levelpre2/`。登録は `--level pre2 --original`。語句整序はない。

## 語彙

高校初級の日常語で書く。本文・選択肢・質問・放送原稿・音読文・絵の描写・参考解答が対象。正解に効く語も、読ませるだけの語も、級の外なら書かない。論理（時刻、条件、誤答が本文の別事実であること）は残し、語だけ替える。

使わないもの:

- 専門の用具・部品・職業（`shin guards`, `kiln`, `reed`, `cartridge`, `tripod`, `wrench`, `custodian`）
- 準2級の定番でない句（`double-booked`, `make an exception`, `the rule applies to`, 書類の意味の `file`）
- 基本の意味でない動詞（`shelve` = 棚に戻す、`advertise`, 庭が `recover` する）

代わりは、その役割を日常の語で言う。例: `sports shoes`, `shirt`, `black ink`, `put books back on the shelf`, `hammer`, `vegetables`, `friends must follow the same rule`。絵で受験者が自分で言う語も、この範囲にする。

## 場面と曜日

学校の日常が一番多くてよい。連絡・部室・提出がほぼ全部にならないようにする。追加するときも、そのファイルの既存問と合わせて見る。

- 学校が主になる問は、形式ごとにだいたい6割まで。残りは家、店、駅、近所が主になるようにする。
- 学校以外を、ボランティア、博物館、図書館だけに寄せない。場所の既定を `club` / `office` / `gym` / `hall` にしない。
- 二つの時刻や曜日を比べて早い方を選ぶ型を、その形式の大半にしない。
- 曜日名が出る問は、月〜日が近い数になるように散らす。曜日のない問に、数を合わせるためだけに曜日を足さない。正解や前後関係の材料になっている曜日は動かさない。
- 既存問の場面や日付を替えるときは、空所の論理、正解番号、各選択肢の役割を残す。本文・誤答・解説・ポイントをセットで直す。リスニングは台本が固まってから、変えた問だけ音声を作り直す。
- 空所の論理は作問スキルの「空所の論理（必須）」。時刻が逆、正解だけが新しい場所や事実、空所の前後で人が消える、【正解】の英文が選択肢と違う、放送に無いバスを正解にする、は未完成。解説で埋め合わせない。

## リーディング

| 枠 | 形 | 長さ・難易度 |
|----|----|-------------|
| 短文の語句空所 | 4肢・1空所 | 語彙か句。2文目・because・that が手がかり。3級の時制・関係代名詞・受動態にしない |
| 会話の空所 | 文の途中の句。4肢 | 1会話は約65語。誤答は会話中の別の事実 |
| 長文の語句空所 | 1本に空所2。4肢は句・節 | 設問は日本語。`Which choice best completes` にしない |
| 内容一致 | メールのあと3問、説明文のあと4問 | メール約200語、説明文約250語以上。質問は言い換え。誤答は本文の別事実（本文が否定している読みを含む） |

内容一致は本文ごとに質問を分ける。共有テンプレートは1本文のあと、その本文の質問だけを出す。1本文に7問を載せない。画面の番号は本文ごとに1からになる。

## ライティング

3級（下線の質問に答える、15〜25語）を使わない。

| 形式 | 形 |
|------|----|
| Eメール | 友人メールは約65〜70語。下線は1か所の短い名詞句（2026年度第1回も `a cleaning event` のベースライン上に細い線がある）。最後は Do you think ...?。返信は、その質問に理由を1つつけて答え、下線の語句について本文にない特徴を2つ聞く。本文40〜50語。話の型は3つ。行った場所＋これから入る設備／移った場所＋そこで見つけたサービス／参加した活動＋そこから得た考え。Do you think は設備・サービス・考えの将来。質問は下線の場所や活動について |
| 意見 | QUESTION は1文。意見と理由2つ。50〜60語 |

メールの採点種別は、問題文に「2つの質問」と「語数の目安」が必要（`exams/writing_feedback.py`）。名前を James にして種別を合わせない。返信欄は空行で区切った次の目印。同じ段落に置くと文字として出る。

```
[[email-form-start]]

Hi, Sam!
Thank you for your e-mail.

[[email-answer-box]]

Best wishes,

[[email-form-end]]
```

`register_writing_questions` は級の既存ライティングを削除する。3級では実行しない。準2級は本番未掲載のローカル差し替えに限る。

## リスニング

話者は `M:` / `W:`。第1部の3肢は放送のみ（txt には書く）。第2部・第3部の4肢は冊子。

| 部 | 形 | 直す基準 |
|----|----|----------|
| 第1部 会話の応答 | 3往復、3肢、イラストなし | 内部 type は `listening_illustration` のまま、画像は空。表示名だけ準2級を「会話の応答」にする。他級はイラスト問題のまま。誤答は会話の別の発話への返事 |
| 第2部 会話の内容 | 4往復、約35〜60語、4肢 | 質問は言い換え。この範囲なら長さのために書き直さない |
| 第3部 文の内容 | 1人、約60語、4肢 | 質問は推測か言い換え。誤答は本文の別事実。時刻や because の写しにしない |

第3部の音声は `utils/text_to_speech_conversation.py --level pre2 --part 3 --passage-txt data/questions/original/levelpre2/listening_passage_questions.txt`。`questions_txt()` は original を指さない。

## スピーキング

約6分。パッセージ約50語。黙読のあと音読。

1. 文章の事実
2. Picture A。複数の人。`Tell me as much as you can about what they are doing.`
3. Picture B。状況（理由を含む）。このあとカードを裏返す（`turn_over_after=3`）
4. 話題への意見。Yes / No と Why
5. 日常。カードの話題だけにしない

No.2 を `What is X doing?` の1動作にしない。音読秒の指定は4級・5級だけ。
