# grammar_fill（文法・語彙）

ファイル: `grammar_fill_questions.txt`  
コマンド: `register_grammar_fill_questions`  
穴埋め 4択。問題文に `( )` を1つ。

## Template

下の英文は形式例（オリジナル）。公式文面ではない。

```
問題1:
A : Ken, please put your bag on the ( ). B : OK.

選択肢1:
1. chair
2. rain
3. song
4. Monday

【正解1】
1. chair

【解説1】
正解は「chair」です。文全体は「ケン、かばんをいすのうえに置いて」「わかった」という意味です。「put A on the chair」で「Aをいすのうえに置く」になります。
ほかの選択肢：「rain（あめ）」「song（うた）」「Monday（げつようび）」は、ものを置く場所ではありません。

---
```

## Rules

- 選択肢は `1.`〜`4.` の4つ。正解は1つ
- 5級: be動詞・一般動詞・身近な名詞／形容詞。語彙は約600〜630語の範囲（色・動物・食べ物・曜日・基本動詞・定型表現など）。1文または短い2人会話。現行公開セットは20問（本番大問1は15問）
- 4級: 前置詞・時制の基本・簡単な助動詞まで。語彙は約900〜1,300語。頻出: `visit`, `forget`, `need to do`, `look for`, `have a good time`。現行公開セットは20問（本番大問1は15問）
- 3級: 接続詞・比較・不定詞・現在完了・受動態のやさしい用法。語彙は約1,210語。4級の焼き直しにしない。現行公開セットは20問（本番大問1は15問）
- 誤答は「別の品詞・別の疑問詞への答え」など学習になるものにする（無関係な語の羅列だけにしない）
- 解説は正解の意味 → 全文の意味 → 各誤答がなぜ合わないか
