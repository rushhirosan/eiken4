# word_order（語順）

ファイル: `wordorder_questions.txt`  
コマンド: `register_wordorder_fill_questions`  
日本語の意味に合うよう、番号チップから指定位置の語を4択で選ぶ。

## 級で枠が違う

| 級 | チップ | 聞く位置 | 枠 |
|----|--------|----------|----|
| 5級 | ①〜④ | 1番目と3番目 | `[1番目] ( ) [3番目] ( )` |
| 4級・3級 | ①〜⑤ | 2番目と4番目 | `( ) [2番目] ( ) [4番目] ( )` |

3級の模試メニューには語順を出さない（ライティング優先）が、練習用 original は4級と同じ5語枠にする。

## Template（5級）

固定部分と①〜④は **重複させない**。

```
問題1:
私は夜，本を読みます。
① books ② at ③ read ④ I
[1番目] ( ) [3番目] ( ) night.

選択肢1:
1. ④ ─ ③
2. ③ ─ ①
3. ④ ─ ①
4. ② ─ ③

【正解1】
3. ④ ─ ①

【解説1】
I read books at night.
1番目は I、3番目は books です。全文は「私は夜、本を読みます」という意味になります。
```

## Template（4級・3級）

①〜⑤が5マス。句を1番号にまとめてよい。

```
問題1:
彼女はとても上手にピアノを弾けます。
① the ② can ③ piano ④ play ⑤ She
( ) [2番目] ( ) [4番目] ( ) well.

選択肢1:
1. ② ─ ①
2. ④ ─ ①
3. ② ─ ④
4. ⑤ ─ ②

【正解1】
1. ② ─ ①

【解説1】
She can play the piano well.
2番目は can、4番目は the です。全文は「彼女はとても上手にピアノを弾けます」という意味です。
```

## Rules

- 日本語文 → チップ → 英語の枠 → 選択肢は `① ─ ③` 形式
- 正解の全文を解説の1行目に書く
- 5級: S+V / S+V+O / 簡単な前置詞句
- 4級: 過去・can / will・疑問文
- 3級: 不定詞・現在完了・Why don't you など

## Mandatory check

全文を `固定前置 + チップの正しい順 + 固定後置` に分解する。

1. チップ数が枠のマス数と一致（5級は4、4/3級は5）
2. **チップの語が枠の固定部分に再度出ていないこと**
3. 【正解】の2ラベルが、分解したマスの指定位置と一致すること（5級は1・3、4/3は2・4）
4. 解説の全文がその分解結果と文字どおり一致する

```bash
python utils/validate_wordorder_questions.py data/questions/original/level{N}/wordorder_questions.txt
```

exit 0 以外ならファイルを直す。通るまで次（酷似・品質）に進まない。
