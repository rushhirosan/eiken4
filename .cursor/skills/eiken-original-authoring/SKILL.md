# Original Question Authoring

子供向けオリジナル練習問題を、公式由来ファイルを見ずに新規作成する。

公開用の置き場は `data/questions/original/level{5|4|3|pre2}/` のみ。既存の `data/questions/*.txt`・`level3/`・`level5/` や `data/pdf_import/` には書かない。準2級の枠は [references/pre2.md](references/pre2.md)。3級の節を準2級に流用しない。

## Inputs to confirm

- 級（`5` / `4` / `3`）。未指定なら **5級**
- カテゴリ（下表）
- 追加数（未指定なら 5〜10）
- 追記か新規ファイルか

## Do not

- 公式PDF（`data/pdf_import/`）を開いて「同じ問題を」と作らない
- 既存の `data/questions/level5|level3|直下` を読んで類題にしない

形式が不明なときは、公式問題文ではなく **このスキルの参照ファイル** と `questions/management/commands/register_*.py` の正規表現を見る。

## Workflow

1. 級・カテゴリ・件数を確定する。級に無いカテゴリなら止める。
2. 該当の `references/*.md` を読む。級が準2級なら、その前に [references/pre2.md](references/pre2.md) を読む。3級用の語数・タスクは使わない。
3. 既存の **original** ファイルがあれば末尾番号を確認する（公式由来ファイルは見ない）。
4. 級の **公式形式表** と該当 `references/*.md` を守って書く。枠・話者・セット構成を独自に変えない。
5. 空所の論理が通った問だけ、解説を書く（詳細は `eiken-explanation-quality-review`）。論理が落ちた問に、解説で辻褄を合わせない。
6. `---` 区切り・連番・選択肢数を崩さない。
7. 追加分の正解番号が極端に偏らないようにする。場面と曜日も、そのファイルの既存問と合わせて寄らないようにする。準2級の目安は [references/pre2.md](references/pre2.md) の「場面と曜日」。
8. **カテゴリ固有の検算**を全問でやる（参照の Mandatory check と、下の「空所の論理」）。語順は枠の手検算に加え、必ず次を実行する:

```bash
python utils/validate_wordorder_questions.py data/questions/original/level{N}/wordorder_questions.txt
```

exit 0 以外なら直し、通るまで次に進まない。
9. 書き終わったら **この場では登録しない**。下の **After writing** の順でレビューへ進む（登録は目視と公開前チェックのあと）。

## Authoring rules

- 難易度・形式は級の傾向に合わせてよい。中身は完全自作
- **語彙・熟語・表現は、その級で意味が取れるものだけを使う。** 一つ上の級の語、専門の用具名・部品名・職業名、基本の意味でない動詞で解かせない。本文・選択肢・質問・放送原稿・絵の描写・参考解答を、書くときに見る。正解に効く語も、本文に出るだけの語も対象
- 級の外の語が手がかりや場面の中心なら、時刻・条件・誤答の役割は残し、語だけ級内のものに替える。熟語は、その級の定番（4級なら `need to do`, `look for`）に限る
- 場面は日常（家・学校・買い物・天気・趣味）。学校が一番多くてよいが、連絡・部室・提出ばかりにしない。曜日名を出す問は月〜日に散らす。準2級の数の目安は [references/pre2.md](references/pre2.md) の「場面と曜日」。固有の組み合わせを公式と共有しない
- 5級: 短文、基本語彙（色・動物・食べ物・曜日・基本動詞・定型表現・前置詞など）、専門用語なし。解説はひらがな多め可
- 4級: 少し長い会話・簡単な接続詞まで。頻出パターン例: `need to do`, `look for`, `have a good time`, `wait for`, `get up`
- 3級: 理由・経験・予定。読解は案内・メール・短い物語。4級の焼き直しにしない
- 準2級: [references/pre2.md](references/pre2.md)。短文空所は語彙・句、メールは Do you think への返答＋質問2つ、内容一致はメール約200語／説明文約250語以上、第1部はイラストなし、第3部は約60語、面接パッセージは約50語。他級に影響させない。高校初級の日常語で書く。用具の専門名、楽器の部品、一つ上の級の句は使わない。外した例は `references/pre2.md` の「語彙」
- 音声は TTS／自作のみ。画像は自作またはライセンス済みのみ（公式切り出し禁止）
- イラストが必要なら、テキストを置いたあと `eiken-listening-illustration-images` を使う。参照画像に `data/archived_media/` は使わない

## 空所の論理（必須）

空所・会話の応答・リスニングの正解は、**空所より前の本文（放送）にすでにある事実だけ**で一つに決める。解説やポイントで後から辻褄を合わせない。1問でも落ちたら、その問は未完成。丁寧な解説を先に書かない。

問ごとに、正解を空所へ入れた全文を読んでから判定する。

1. **時刻は、正解の動作が間に合う側に置く。** `because` / `only if` / `before` / `after` の理由と、正解の動作を時刻順に並べる。理由が正解より前で、もう終わっているなら不可。使うのが日曜の朝で、別のクラブに必要なのがその前の土曜の夜、なのに「8時前にいすを重ねる」は、終わった夜に間に合わない。次のクラブが9時に来るので、8時前に重ねて返す、なら可。
2. **正解に出る場所・人・物は、空所より前で一つに決まっている。** 本文が東口、正解が花屋、で本文が二つを同じ場所だと書いていなければ不可。先に `the flower shop at the east exit` と一つにする。解説とポイントも、本文が結んでいない二つを同じものと呼ばない。
3. **正解だけが新しい事実を持たない。** 温かいご飯、仕事を見せてもらえるときだけ、のように、空所を埋めて初めて出てくる中身は不可。その事実は空所の前の文に書く。空所が担う部分（1週間後、だけ、より頻繁に）は本文に書かず、選択肢に残す。
4. **空所の前後は同じ人の動作。** 前が `The writer did not add` なら、うしろも `the writer added`。`appeared` のように、誰がしたかを消さない。
5. **【正解】の英文は、その番号の選択肢と一字一句同じ。** 読解の登録は、番号を外したあと文言が一致した選択肢だけを正解にする。選択肢が `neighbors` で正解行が `friends` だと、正解が付かない。
6. **リスニングの正解は、放送がすでに言ったことの組み合わせ。** 博物館行きと言ったのが12番だけなのに、正解が8番、は不可。乗る候補は先に全部言う。外す方は名指しする（`The number 12 left`。候補が2つあるとき `It left` にしない）。台本を変えた問だけ、音声を作り直す。
7. **落ちたときは本文側を直す。** 正解番号と、各誤答の役割（締め出す、別の疑問への返事、本文が否定した行動）は残す。

## After writing

カテゴリごと（またはまとめて）この順。飛ばさない。**登録は人の目視と公開前チェックのあと**。

1. 作問（このスキル。テキストを `original/level{N}/` に置く）
2. `eiken-originality-review`（同一カテゴリの類似・公式由来との酷似・本当に original か）
3. `eiken-explanation-quality-review`（懇切丁寧）
4. `eiken-question-quality-review`（級適合・ダミーの質・正解偏り・空所の論理）
5. **人の目視**（公式公開過去問と並べて酷似最終確認。スキルの代用ではない）
6. **公開前チェック**（`.cursor/rules/original-questions.mdc`。1つでも未なら登録しない）
7. 登録・ローカル確認（`--original` など。目視・公開前チェックの前に登録しない）

級の最小セットを積み上げるときは、カテゴリごとに 1〜4 を回し、セットが揃ってから 5→6→7 でもよい。いずれにせよ **7 の前に 5 と 6**。

登録コマンドの既定はレガシー取り込みを `blocked` にする。`original` は明示した新規だけ。
