# Question Quality Review

オリジナル問題の **学習品質** を見る。公式との酷似は扱わない → `eiken-originality-review`。解説の丁寧さは扱わない → `eiken-explanation-quality-review`。

## Inputs to confirm

- 級（`5` / `4` / `3`）
- カテゴリ
- 対象範囲（全件 or 番号レンジ）
- 改訂方針（最小修正 / 積極修正）

対象は `data/questions/original/level{N}/`。公式由来ファイルを直して「オリジナルにする」作業はしない。

## Review focus

1. **級適合**: 語彙・文法・文長がその級か。下記「級適合の客観基準」で感覚判断にしない
2. **選択肢**: ダミーが不自然な英語／明らかにハズレすぎ／正解が文脈上複数、がないか
3. **正解偏り**: 対象範囲で 1〜4 が極端に偏っていないか
4. **形式**: 番号、`---`、【正解】【解説】、選択肢数
5. **自作内の重複**: 人名だけ違う同型。IP 用の公式比較は originality 側
6. **構造の正しさ（カテゴリ別）**: 見た目の丁寧さより先に、枠と正解が機械的に成り立つか。**公式形式は `eiken-original-authoring` の「公式形式」表と一致させる**（独自の語順枠・読解セット・スピーキング配分にしない）

### 級適合の客観基準（感覚判断にしない）

公開情報（英検協会の試験要項・各対策サイトの試験概要）を **形式・語彙レンジ・配分の目安** として使う。問題文・選択肢・解説のコピーはしない。

| 級 | レベル目安 | 語彙目安 | 本番 R 配分 | 本番 L 配分 | 面接 | ライティング |
|----|-----------|---------|------------|------------|------|-------------|
| 5 | 中学初級（中1修了） | 約600〜630語 | 15 / 5 / 5（25分） | 10 / **5** / 10（約20分） | なし | なし |
| 4 | 中学中級（CEFR A1） | 約900〜1,300語 | 15 / 5 / 5 / **10**（35分） | 10 / 10 / 10（約30分） | なし | なし |
| 3 | 中学卒業（CEFR A1） | 約1,210語 | 15 / 5 / 10 | 10 / 10 / 10 | あり | メール15–25語＋意見25–35語 |

合格ラインの目安（CSE）: 5級 419/850、4級 622/1000、3級一次 1103/1650。正答率の目安はおおむね **6〜7割**。

**級適合 NG の目安**

- 対象範囲の **3割超** が「一つ下の級でも解ける」難易度（5級に be/一般動詞のみ、4級に色・数字だけ、3級に4級の焼き直し）
- 語彙がその級の上限を明らかに超え、解説でも補えない（5級に `although`、4級に `present perfect`、3級に準2級語）
- 3級 `writing` に Eメールと意見論述の **両形式がそろっていない**（形式欠落は品質以前の不備）
- 公開セット件数が本番配分と大きく違うとき、意図（練習用増量）の記載がなく偏りが生じている

**大問別の見るポイント**

| 大問 | 5級 | 4級 | 3級 |
|------|-----|-----|-----|
| 文法・語彙 | be/一般動詞・身近名詞。短文 | 前置詞・時制・簡単な助動詞。頻出: `need to do`, `look for` | 接続詞・比較・不定詞・現在完了・受動態（やさしい） |
| 会話 | 誤答は別の疑問詞への答え | 誤答は聞き違い・会話の流れ違い | 理由・経験・予定。4級より長く |
| 語順 | 日本文つき。①〜④の1・3番目 | 日本文つき。①〜⑤の2・4番目 | 4級と同枠。3級文法を混ぜる |
| 読解 | なし | 掲示・メール・説明文の内容一致 | 同セット構成。文長は3級基準 |
| L応答 | Part1 応答3択（★／☆） | 大問1は **3択・選択肢読み上げ** | 4級と同型。理由・条件を混ぜる |

公開セット件数と本番配分の対応は `eiken-original-authoring` の「本番出題数と公開セット」を参照。件数が本番より多いのは練習用増量としてよいが、**難易度が本番比率に対して偏っていないか** はここで見る。

### 級別形式チェック（品質レビューでも見る）

- 語順: 5級は①〜④の1・3番目、4/3級は①〜⑤の2・4番目。**4/3級は日本文つき**
- 読解（4/3のみ）: 1セットが掲示2＋メール3＋物語5。公開は2セット
- スピーキング: 5級は内容2＋自分1（イラストなし）。4級は内容2＋イラスト1＋自分1。3級は内容1＋イラスト2＋自分2
- L会話: 5級は☆／★＋`☆☆`（本番第2部は5問）。4/3級は M: / W:（`☆☆` なし）
- Lイラスト: 5級 Part1 は応答3択（本番10問）、Part3（101+）はイラスト一致（本番10問）。4/3級は会話と画像が矛盾しない。4級大問1は3択読み上げ
- 5級に読解・ライティング・L文章を足していないか。4級にライティング・面接を足していないか

### word_order 必須検算

各問について解説の全文を、枠の `固定前置 + チップ順 + 固定後置` に分解する。

- チップ数＝枠のマス数（5級は①〜④の4マス、4級・3級は①〜⑤の5マス）
- 【正解】のラベルが指定位置と一致すること（5級は1番目・3番目、4/3級は2番目・4番目）
- **チップの語が枠の固定部分に再度出ていないこと**（`friends` が③と枠末尾の両方、など）
- 1問でも落ちたら「通す」にしない。直すか差し替える

酷似チェック（`eiken-originality-review`）は文面の近さだけ見る。**この構造バグは originality では拾えない**ので、品質レビュー側の担当。

語順は手検算に加え、必ずスクリプトを実行する:

```bash
python utils/validate_wordorder_questions.py data/questions/original/level{N}/wordorder_questions.txt
```

**original 全カテゴリ**（語順以外も含む）は Phase 2 バリデータを必ず通す:

```bash
python utils/validate_original_questions.py --level {N}
# または全級
python utils/validate_original_questions.py
```

`./scripts/preflight-original.sh` も内部で実行する。ERROR 0 でない限り「品質 OK」にしない。WARN（正解偏り）は内容を確認する。

## Workflow

1. 対象ファイルと範囲を特定する。
2. **級適合の客観基準**（語彙レンジ・本番配分・大問別ポイント）で全体の難易度と形式欠落を先に確認する。
3. カテゴリ固有の構造検算をやる（語順は上記スクリプト）。
4. 問ごとにその他の懸念をリストする。
5. 最小修正を優先して直す。意図を壊す大改造はしない。
6. 正解番号だけ動かして偏りを消さない。選択肢全体が自然なままにする。
7. 変更理由を1行で残す。

## Revision policy

- 5級の難語は身近な語に置き換える
- 複数正解になる空所は、文脈を足して1つにする
- 意味不明なダミーは「別の疑問詞への答え」など、ありそうな誤りにする
- 酷似の疑いは直さず、`eiken-originality-review` に回す

## Output format

- 修正した問題番号と理由（1行）
- 未修正で残したものと理由
- 酷似の疑いは番号だけ列挙し、originality-review へ

```bash
python utils/check_answer_distribution.py
```

（分布スクリプトが original パス未対応なら、対象ブロックの正解番号を数える。）
