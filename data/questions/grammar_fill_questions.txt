A : Mom, I want to make some cookies.
B : All right, but please ( ) this carrot first.

選択肢168:
1. cut
2. arrive
3. hit
4. run

【正解168】
1. cut

【解説168】
クッキーを作る前ににんじんを「cut（切る）」のが自然です。まずにんじんを切って、というお願いです。他の選択肢「arrive this carrot（到着する）」「hit this carrot（打つ）」「run this carrot（走る）」は意味が通じません。
