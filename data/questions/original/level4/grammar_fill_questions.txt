問題1:
A : Where is my notebook? B : It's ( ) the desk, next to the lamp.

選択肢1:
1. under
2. on
3. between
4. during

【正解1】
2. on

【解説1】
正解は「on」です。意味は「〜のうえに」です。
文全体は「ノートはどこ？」「机のうえだよ。ランプのとなり」という会話です。「on the desk」で「机のうえ」になります。うしろの「next to the lamp（ランプのとなり）」も、机の表面に置いてあるイメージと合います。
ほかの選択肢：場所のまちがいとして「under（〜のした）」は机の下になり、「next to the lamp」と合いにくいです。「between（〜のあいだ）」は二つのものの間に使います。「during（〜のあいだ）」は時間用なので、机の位置には使えません。
ヒント：「Where」の答えで「机のどこ？」と聞かれたら、on / under / in など位置の語を比べましょう。

問題2:
Yuki ( ) a postcard to her grandmother last Sunday.

選択肢2:
1. sent
2. sends
3. sending
4. send

【正解2】
1. sent

【解説2】
正解は「sent」です。意味は「送った」です（send の過去形）。
文全体は「ユキは先週の日曜日に、おばあちゃんにはがきを送りました」という意味です。「last Sunday（先週の日曜日）」があるので、過去のできごとです。過去形は主語が誰でも形は同じで、「sent」になります。
ほかの選択肢：いまの話なら「sends」、進行なら「is sending」、命令や助動詞のあとなら「send」ですが、どれも「last Sunday」とは合いません。
ヒント：文の終わりに yesterday / last 〜 / ago があったら、まず過去形を疑いましょう。

問題3:
A : It's cold outside. B : You ( ) wear a coat.

選択肢3:
1. may not
2. don't have
3. should
4. are

【正解3】
3. should

【解説3】
正解は「should」です。意味は「〜したほうがよい」です。
文全体は「外は寒いよ」「コートを着たほうがいいよ」という会話です。「should + 動詞の原形」でアドバイスになります。「wear a coat」で「コートを着る」です。
ほかの選択肢：「may not」は「〜しないかもしれない／〜してはいけない」寄りで、勧めになりません。「don't have」のあとに「wear」は続かず、形が足りません（「don't have to」なら「しなくてもよい」）。「are」のあとに「wear」は続きません（「are wearing」なら進行形）。
ヒント：相手に「こうしたほうがいいよ」と言うときは should + 原形、と覚えておくとよいです。

問題4:
Please ( ) the fan. The kitchen smells like fish.

選択肢4:
1. throw away
2. look for
3. put on
4. turn on

【正解4】
4. turn on

【解説4】
正解は「turn on」です。意味は「（スイッチを）つける」です。
文全体は「扇風機をつけてください。キッチンが魚のにおいがします」という意味です。においをやわらげるために風を送るので、「turn on the fan」が自然です。
ほかの選択肢：「throw away（捨てる）」は扇風機を捨てることになり不自然です。「look for（探す）」は、すでに対象があるお願い文に合いません。「put on」は服を「着る／履く」ときに使い、扇風機のスイッチには使いません。
ヒント：電気製品のスイッチは turn on（つける）／ turn off（消す）のセットで覚えると便利です。

問題5:
There is a small bridge ( ) the river and the hill path.

選択肢5:
1. along
2. between
3. without
4. about

【正解5】
2. between

【解説5】
正解は「between」です。意味は「（二つのものの）あいだに」です。
文全体は「川と丘の道のあいだに、小さな橋があります」という意味です。「A and B」と二つのものが並んでいるときは、「between A and B」を使います。
ほかの選択肢：「along（〜にそって）」は道などに使います。「without（〜なしで）」と「about（〜について／およそ）」は、二つの場所のあいだ、という位置の意味にはなりません。
ヒント：「〜 and 〜」のあいだの位置なら、まず between を思い浮かべましょう。

問題6:
A : Do you want to see a movie tomorrow? B : Sure. I ( ) meet you at six.

選択肢6:
1. will
2. was
3. am
4. did

【正解6】
1. will

【解説6】
正解は「will」です。意味は「〜するつもりだ／〜するよ」です。
文全体は「明日映画を見ない？」「いいよ。6時に会おう」という会話です。「tomorrow」などこれからすることなので、「will + 動詞の原形（meet）」を使います。
ほかの選択肢：「was」「did」は過去の話です。「am」のあとに「meet」は続きません（「am meeting」なら進行形）。
ヒント：約束やこれから決めた行動は will + 原形、とセットで覚えましょう。

問題7:
A : Why is Mia wearing boots today? B : She is wearing them ( ) the ground is muddy.

選択肢7:
1. if
2. although
3. unless
4. because

【正解7】
4. because

【解説7】
正解は「because」です。意味は「なぜなら〜だから」です。
文全体は「なぜミアは今日ブーツを履いているの？」「地面がぬかるんでいるから履いているんだ」という意味です。「Why」で理由を聞いているので、答えは「because ...」が自然です。
ほかの選択肢：「if（もし〜なら）」と「unless（〜しない限り）」は条件です。「although（〜だけれど）」は逆接で、理由の答えにはなりません。
ヒント：「Why ...?」と見たら、because で始まる理由の文を探しましょう。

問題8:
My sister can ( ) a bike without help now.

選択肢8:
1. rides
2. riding
3. ride
4. rode

【正解8】
3. ride

【解説8】
正解は「ride」です。意味は「乗る」の原形です。
文全体は「姉（妹）はいま、助けなしで自転車に乗れます」という意味です。「can」のあとは必ず動詞の原形が来るので、「can ride」になります。
ほかの選択肢：「rides」は三人称単数の現在形、「riding」は -ing 形、「rode」は過去形で、どれも can の直後には置けません。
ヒント：can / will / should などの助動詞のあとは、いつも動詞の原形、と覚えましょう。

【正解9】

問題10:
We ( ) a board game if we finish our homework early.

選択肢10:
1. played
2. plays
3. playing
4. will play

【正解10】
4. will play

【解説10】
正解は「will play」です。意味は「するつもりです／するでしょう」です。
文全体は「宿題を早く終わらせたら、ボードゲームをします」という意味です。「if + 現在形（finish）」のあとで、これからすることを言うときによく「will」を使います。
ほかの選択肢：「played」は過去形で、これからする話には合いません。「plays」は三人称単数の現在形で、主語が「We」なので合いません。「playing」だけでは文として足りません（「are playing」なら別）。
ヒント：if の節が現在形なら、あとの節は will + 原形、という型を覚えておくとよいです。

問題11:
A : Where should I keep the markers? B : Please put them ( ) the box.

選択肢11:
1. at
2. in
3. on
4. to

【正解11】
2. in

【解説11】
正解は「in」です。意味は「〜の中に」です。
文全体は「マーカーはどこにしまえばいい？」「箱の中に入れてね」という会話です。「in the box」で「箱の中」になります。
ほかの選択肢：「at」は地点（at the station など）に使い、箱の中には合いません。「on」は「〜のうえ」なので、箱のフタのうえに置く意味になり、しまう動作とずれます。「to」は方向（〜へ）なので、「箱の中に入れる」意味にはなりません。
ヒント：箱・引き出し・かばんの「中」なら in、「表面のうえ」なら on をまず比べましょう。

問題12:
Sota ( ) eat breakfast yesterday because he woke up late.

選択肢12:
1. didn't
2. don't
3. doesn't
4. isn't

【正解12】
1. didn't

【解説12】
正解は「didn't」です。意味は「〜しなかった」です。
文全体は「ソータはきのう、おそく起きたので朝ごはんを食べませんでした」という意味です。「yesterday（きのう）」があるので過去の否定で、「didn't + 動詞の原形（eat）」になります。
ほかの選択肢：「don't」は現在の否定（I / you / we / they）、「doesn't」は現在の否定（he / she）で、どちらも「yesterday」と合いません。「isn't」は be動詞の否定で、あとに「eat」は続きません。
ヒント：yesterday / last 〜 の否定は didn't + 原形、とそろえましょう。

問題13:
You ( ) take off your shoes at the front door.

1. are

3. have to
4. having

【正解13】
3. have to

問題15:

1. during
2. between

4. without

【解説15】

問題16:
The science room ( ) open last night. The lights were off.

選択肢16:
1. isn't
2. aren't
3. wasn't
4. weren't

【正解16】
3. wasn't

【解説16】
正解は「wasn't」です。意味は「〜ではありませんでした」（is not の過去）です。
文全体は「理科室は昨夜、開いていませんでした。電気が消えていました」という意味です。「last night」があるので過去です。主語の The science room は一つなので、単数の「wasn't」を使います。
ほかの選択肢：「isn't」と「aren't」はいまの話で、「last night」と合いません。「weren't」は過去ですが、主語が複数（they / the rooms など）のときに使います。
ヒント：be動詞の過去は was / were。一つなら was / wasn't、二つ以上なら were / weren't です。

問題17:
I collected sea shells ( ) I was little.

選択肢17:
1. if
2. when
3. after
4. until

【正解17】
2. when

【解説17】
正解は「when」です。意味は「〜のとき」です。
文全体は「小さいころ、私は貝がらを集めていました」という意味です。「I was little」は時期を示すので、「when（〜のとき）」が自然です。

ヒント：子どものころ／そのとき、という時期なら when を選びましょう。

問題18:
A : What do you want to do on Sunday? B : I ( ) visit the new city farm.

選択肢18:
1. would like
2. am wanting
3. wants to
4. would like to

【正解18】
4. would like to

【解説18】
正解は「would like to」です。意味は「〜したい」です（want to よりていねい）。
文全体は「日曜日は何がしたい？」「新しい市民農園へ行きたいな」という会話です。「would like to + 動詞の原形（visit）」で希望を表します。

ヒント：「〜したい」は want to / would like to + 原形。I のあとは wants にしない、と覚えましょう。

選択肢19:
1. are

【正解19】
