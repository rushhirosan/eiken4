問題1:
A : Why did you stay home yesterday? B : ( ) I had a headache.

選択肢1:
1. Although
2. Because
3. Before
4. Until

【正解1】
2. Because

【解説1】
正解は「Because」です。意味は「〜なので／なぜなら」です。
文全体は「きのう、なぜ家にいたの？」「頭痛がしたから」という会話です。「Why」で理由を聞いているので、「Because + 理由」が自然です。
ほかの選択肢：「Although（〜だけれども）」は逆の内容をつなぎます。「Before（〜の前に）」「Until（〜まで）」は時間のつなぎで、理由の答えになりません。
ヒント：Why のあとにくる答えは、だいたい Because から始まります。

【ポイント1】
種別: 文法
見出し: Why の答えは Because（理由を表すつなぎ言葉）
・Because I was sick. のように Because + 主語 + 動詞
・Although は逆接、Before / Until は時を表す
・理由が名詞ひとつなら because of を使う

問題2:
This bag is ( ) than that one, so I can carry it easily.

選択肢2:
1. lighter
2. light
3. lightest
4. more light

【正解2】
1. lighter

【解説2】
正解は「lighter」です。意味は「より軽い」です（light の比較級）。
文全体は「このかばんはあれより軽いので、かんたんに持てる」という意味です。「than」があるので比較級が必要です。短い形容詞は「-er」をつけます。
ほかの選択肢：「light」は原級で、「than」と合いません。「lightest」は最上級で、「than」とは使いません。「more light」は形がまちがいです（light は lighter）。
ヒント：than が見えたら比較級（-er / more 〜）を探しましょう。

【ポイント2】
種別: 文法
見出し: than があれば比較級（短い形容詞は -er）
・light → lighter → lightest
・最上級は than ではなく in / of と使う
・more light のように more と -er を混ぜない
