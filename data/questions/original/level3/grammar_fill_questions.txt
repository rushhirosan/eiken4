問題1:
A : Why did you stay home yesterday? B : ( ) I had a headache.

選択肢1:
1. Although
2. Because
3. Before
4. Until

【正解1】
2. Because

【解説1】
正解は「Because」です。意味は「〜なので／なぜなら」です。
文全体は「きのう、なぜ家にいたの？」「頭痛がしたから」という会話です。「Why」で理由を聞いているので、「Because + 理由」が自然です。
ほかの選択肢：「Although（〜だけれども）」は逆の内容をつなぎます。「Before（〜の前に）」「Until（〜まで）」は時間のつなぎで、理由の答えになりません。
ヒント：Why のあとにくる答えは、だいたい Because から始まります。

問題2:
This bag is ( ) than that one, so I can carry it easily.

選択肢2:
1. lighter
2. light
3. lightest
4. more light

【正解2】
1. lighter

【解説2】
正解は「lighter」です。意味は「より軽い」です（light の比較級）。
文全体は「このかばんはあれより軽いので、かんたんに持てる」という意味です。「than」があるので比較級が必要です。短い形容詞は「-er」をつけます。
ほかの選択肢：「light」は原級で、「than」と合いません。「lightest」は最上級で、「than」とは使いません。「more light」は形がまちがいです（light は lighter）。
ヒント：than が見えたら比較級（-er / more 〜）を探しましょう。

問題3:
A : Do you want ( ) with us after school? B : Sure. I'd love to.

選択肢3:
1. go
2. going
3. to go
4. went

【正解3】
3. to go

【解説3】
正解は「to go」です。「want to + 動詞の原形」で「〜したい」という意味になります。
文全体は「放課後、いっしょに行きたい？」「うん、ぜひ」という会話です。
ほかの選択肢：「go」だけだと want のあとに続きません。「want going」はふつう使いません。「went」は過去形なので、いまの希望には合いません。
ヒント：want / hope / decide のあとは to + 原形、とセットで覚えましょう。

問題4:
I have already ( ) my homework, so I can watch TV now.

選択肢4:
1. finish
2. finishing
3. finishes
4. finished

【正解4】
4. finished

【解説4】
正解は「finished」です。「have + 過去分詞」で現在完了になります。
文全体は「もう宿題を終わらせたから、いまテレビを見ていい」という意味です。「already（もう）」も、いままでの完了を示すサインです。
ほかの選択肢：「finish / finishes」は現在形で、have のあとに続きません。「finishing」は進行の形で、ここには合いません。
ヒント：have / has のあとにくる動詞は、過去分詞（多くは -ed）です。

問題5:
The window ( ) by my brother this morning.

選択肢5:
1. broke
2. was broken
3. is breaking
4. broken

【正解5】
2. was broken

【解説5】
正解は「was broken」です。「be動詞 + 過去分詞」で受動態（〜される／〜された）になります。
文全体は「その窓はけさ、兄に壊された」という意味です。「by my brother」があるので、動作を受けた側が主語の形が自然です。
ほかの選択肢：「broke」は能動態で、「by 〜」と並べると意味がぎこちなくなります。「is breaking」は進行形で、けさのできごとには合いにくいです。「broken」だけだと文の動詞が足りません。
ヒント：by 〜（〜によって）が見えたら、受動態を疑いましょう。

問題6:
A : Is this the book ( ) you bought last week? B : Yes, it is.

選択肢6:
1. that
2. what
3. who
4. where

【正解6】
1. that

【解説6】
正解は「that」です。ここでは「先週買った（その）本」のように、前の名詞（book）を説明する関係代名詞です。
文全体は「これが、きみが先週買った本？」「うん」という会話です。物を指すので that / which が使えます。
ほかの選択肢：「what」は「〜するもの」の意味で、前に名詞がある形にはふつう使いません。「who」は人用です。「where」は場所の関係詞で、ここでは合いません。
ヒント：人→who、物→that / which、と分けると迷いにくいです。

問題7:
If it ( ) tomorrow, we will cancel the picnic.

選択肢7:
1. will rain
2. raining
3. rained
4. rains

【正解7】
4. rains

【解説7】
正解は「rains」です。「If + 現在形, will + 原形」で「もし〜なら、〜するだろう」という未来の条件を表します。
文全体は「もしあした雨なら、ピクニックはやめます」という意味です。if 節の中では will を使わず、現在形にします。
ほかの選択肢：「will rain」は if 節ではふつう使いません。「raining」だけでは動詞の形が足りません。「rained」は過去で、あしたの話に合いません。
ヒント：If の中は現在形、あとの文は will、とセットで覚えましょう。

問題8:
A : How long have you played the piano? B : ( ) I was eight years old.

選択肢8:
1. For
2. During
3. Since
4. Until

【正解8】
3. Since

【解説8】
正解は「Since」です。意味は「〜からずっと」です。
文全体は「ピアノをどのくらい弾いているの？」「8歳のときから」という会話です。「How long」に対して、開始時点を言うときは since、期間の長さを言うときは for を使います。
ほかの選択肢：「For」のあとは「for three years」のように長さが来ます。「During」は「during the summer」のように期間の名詞と使います。「Until」は「〜まで」で、継続の開始を言う形ではありません。
ヒント：since + 時点、for + 期間、と覚えると答えやすいです。

問題9:
It is important ( ) breakfast every morning.

選択肢9:
1. eat
2. to eat
3. eating
4. ate

【正解9】
2. to eat

【解説9】
正解は「to eat」です。「It is + 形容詞 + to + 原形」で「〜することは…だ」という意味になります。
文全体は「毎朝朝ごはんを食べることは大切です」という意味です。
ほかの選択肢：「eat / ate」だけではこの形に続きません。「eating」を使うなら「Eating breakfast is important」のように主語にする別の文になります。
ヒント：It is fun / easy / important to 〜 の型をそのまま覚えましょう。

問題10:
My sister speaks English as ( ) as her teacher.

選択肢10:
1. well
2. good
3. better
4. best

【正解10】
1. well

【解説10】
正解は「well」です。「as + 原級 + as」で「〜と同じくらい…」という意味です。動詞 speak を修飾するので副詞の well を使います。
文全体は「姉は先生と同じくらいうまく英語を話します」という意味です。
ほかの選択肢：「good」は形容詞で、speak の様子にはふつう使いません。「better / best」は比較・最上級で、as 〜 as の間には原級が入ります。
ヒント：as 〜 as の間は原級。うまく〜する、なら well です。
