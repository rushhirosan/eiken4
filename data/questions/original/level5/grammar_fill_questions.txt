問題1:
A : The cat is hungry. Please give it some ( ). B : OK.

選択肢1:
1. songs
2. food
3. rain
4. Tuesday

【正解1】
2. food

【解説1】
正解は「food」です。意味は「たべもの」です。
文全体は「ネコがおなかをすかせているよ。たべものをあげて」「わかった」という会話です。「give it some food」で「ネコにたべものをあげる」になります。
ほかの選択肢：「songs（うた）」は音楽、「rain（あめ）」は天気、「Tuesday（かようび）」は曜日で、どれも食べものではありません。
「hungry（おなかがすいた）」のあとに、食べものが入るか見てみましょう。

問題2:
Sora has a ( ) on the wall. It shows Japan and many cities.

選択肢2:
1. clock
2. sock
3. cloud
4. map

【正解2】
4. map

【解説2】
正解は「map」です。意味は「ちず」です。
文全体は「ソラはかべにちずを持っています。にほんといくつものまちがのっています」という意味です。にほんやまちがのっているものは「map（ちず）」です。
ほかの選択肢：「clock（とけい）」はかべにあっても、まちはのっていません。「sock（くつした）」は足に履くもの、「cloud（くも）」はそらにあるもので、かべにまちを見せるものではありません。
うしろの文で「何がのっているか」を読むと、正解がわかります。

問題3:
A : I'm sleepy. B : Here's a ( ).

選択肢3:
1. pillow
2. homework
3. jacket
4. station

【正解3】
1. pillow

【解説3】
正解は「pillow」です。意味は「まくら」です。
文全体は「ねむいよ」「はい、まくらだよ」という会話です。「sleepy」は「ねむい」という意味です。ねむいときに渡すなら、ねるときに使う「pillow（まくら）」が合います。
ほかの選択肢：「homework（しゅくだい）」は勉強、「jacket（うわぎ）」はさむいときの服、「station（えき）」はばしょで、ねむいときに渡すものではありません。
「sleepy（ねむい）」と来たら、ねるどうぐを探すとよいです。

問題4:
Ms. Mori is in the kitchen. She is making ( ) for lunch.

選択肢4:
1. a bus
2. a song
3. soup
4. a bed

【正解4】
3. soup

【解説4】
正解は「soup」です。意味は「スープ」です。
文全体は「モリせんせいはだいどころにいます。ひるごはんのスープをつくっています」という意味です。「make soup」で「スープをつくる」になります。だいどころでひるごはんにつくるものは、食べものです。
ほかの選択肢：「a bus（バス）」は乗り物、「a song（うた）」は音楽、「a bed（ベッド）」はねる家具で、ひるごはんのメニューではありません。
「kitchen（だいどころ）」と「lunch（ひるごはん）」の二つを見ると、食べものが入ります。

問題5:
A : Let's play ( ) after school. B : Great! I have a ball.

選択肢5:
1. piano
2. soccer
3. music
4. house

【正解5】
2. soccer

【解説5】
正解は「soccer」です。意味は「サッカー」です。

ほかの選択肢：「piano（ピアノ）」は「play the piano（ピアノをひく）」と the がつくことが多いです。「music（おんがく）」と「house（おうちごっこ）」はボールを使いません。
「I have a ball.（ボールを持っている）」を見ると、ボールでする遊びが選べます。

問題6:
Look at the sky at night. You can see the ( ).

問題7:
A : Where are my socks? B : They're in the ( ).

選択肢7:
1. rain
2. August
3. yellow
4. box

【正解7】
4. box

【解説7】
正解は「box」です。意味は「はこ」です。
文全体は「ぼくのくつしたはどこ？」「はこのなかだよ」という会話です。「Where」は「どこ」とばしょを聞くことばです。入るのは、ばしょを表すことばです。
ほかの選択肢：「rain（あめ）」は天気、「August（8がつ）」は月のなまえ、「yellow（きいろ）」は色で、ばしょではありません。
「Where（どこ）」と聞かれたら、ばしょの答えを探すとよいです。

問題8:
It's a ( ) day. We can fly a kite in the park.

選択肢8:
1. sleepy
2. rainy
3. windy
4. hungry

【正解8】
3. windy

【解説8】
正解は「windy」です。意味は「かぜがつよい」です。
文全体は「かぜのつよい日です。こうえんでたこをあげられます」という意味です。「fly a kite」は「たこをあげる」です。かぜがつよいと、たこがよくあがります。
ほかの選択肢：「rainy（あめの）」日はたこがぬれてしまいます。「sleepy（ねむい）」と「hungry（おなかがすいた）」は人の気持ちで、天気ではありません。
うしろに「fly a kite（たこをあげる）」があると、天気のことばのなかでも、かぜに関係するものが入ります。

問題9:
A : I want to color this picture. B : Here's a ( ). It's on the desk.

選択肢9:
1. umbrella
2. crayon
3. banana
4. ticket

【正解9】
2. crayon

【解説9】
正解は「crayon」です。意味は「クレヨン」です。

ほかの選択肢：「umbrella（かさ）」は雨のとき、「banana（バナナ）」は食べもの、「ticket（きっぷ）」はのりものに乗るときで、絵に色はぬれません。
「color（色をぬる）」と「picture（絵）」を見ると、ぬるどうぐが浮かびます。

問題10:
Hana ( ) her bike to the library on Saturday.

選択肢10:
1. rides
2. drives
3. opens
4. cooks

【正解10】
1. rides

【解説10】
正解は「rides」です。意味は「のる」です。
文全体は「ハナはどようびに、じてんしゃにのって図書館（としょかん）へ行きます」という意味です。「ride a bike」で「じてんしゃにのる」になります。
ほかの選択肢：「drives（うんてんする）」はくるまに使います。「opens（あける）」と「cooks（りょうりする）」は、じてんしゃのあとに続くことばではありません。
「bike（じてんしゃ）」の前には「ride（のる）」がよく来ます。くるまなら drive です。
