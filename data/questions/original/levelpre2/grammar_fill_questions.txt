問題1:
The hiking club had walked for two hours when fog covered the trail. Their leader checked a map and a ( ) so the group could tell which way was north.

選択肢1:
1. suitcase
2. receipt
3. compass
4. keyboard

【正解1】
3. compass

【解説1】
空所のあと so the group could tell which way was north とあります。北の方角を知るために地図と一緒に見るものはコンパスです。2文目が、空所の語の意味を決めています。
1 suitcase は旅行かばんです。霧の中の方角には使いません。2 receipt はレシートで、支払いの記録です。4 keyboard はコンピュータのキーボードです。どれも「どちらが北か」を教えません。

【ポイント1】
種別: 文法
見出し: 2文目が語の意味を決める
・空所の語は、あとの so ... で何に使うかが分かる
・選択肢はすべて名詞。文法ではなく意味で選ぶ
・north と一緒に使うのは compass

Every club may use the new printer. The rule does not include the newspaper club, which has its own machine. All clubs ( ) the newspaper club should sign the sheet.

選択肢46:
1. according to
2. instead of
3. because of
4. except for

【正解46】
4. except for

【解説46】
does not include the newspaper club が、署名の対象から外すクラブを決めています。新聞部以外のすべてのクラブが用紙に署名します。except for は「〜を除いて」です。
1 according to は「〜によれば」で、新聞部という除外の意味にはなりません。2 instead of は「〜の代わりに」で、新聞部が署名する側になってしまいます。3 because of は「〜が原因で」です。

【ポイント46】
種別: 熟語
見出し: except for = 「〜を除いて」
・除外の理由 ← which has its own machine
・instead of = 「〜の代わりに」（除外ではない）
・All ... except for → 一人だけ外す型

問題47:
The trails are not all easy. The guide will ( ) the east path to beginners, because it has no steep steps.

選択肢47:
1. recommend
2. recognize
3. recycle
4. repeat

【正解47】
1. recommend

【解説47】
全部の道が易しいわけではない、と、東の道には急な段がない、が手がかりです。初心者には東の道を勧めます。recommend A to B は「BにAを勧める」です。
2 recognize は「見分けがつく」で、to beginners への勧めにはなりません。3 recycle は「再利用する」です。4 repeat は「繰り返す」です。no steep steps は、勧める理由です。

【ポイント47】
種別: 単語
見出し: recommend A to B = 「AをBに勧める」
・この文の A は道、B は初心者
・選んで勧める必要がある ← not all easy
・recognize = 「見分けて分かる」

問題48:
Wet shoes left in the hallway have caused falls. The box by the door is there to ( ) that problem, because students can change shoes before they walk in.

選択肢48:
1. cause
2. prevent
3. pretend
4. predict

【正解48】
2. prevent

【解説48】
濡れた靴が転倒を起こしているので、ドアのそばの箱は、その問題を防ぐためのものです。中に入る前に履き替えられます。prevent は「防ぐ」です。
1 cause は「引き起こす」で、箱の目的と逆です。3 pretend は「ふりをする」です。4 predict は「予測する」で、履き替えの箱の働きではありません。

【ポイント48】
種別: 単語
見出し: prevent = 「防ぐ」
・過去に起きた困りごと ← have caused
・防ぐ方法 ← change shoes
・cause = 「引き起こす」（prevent の反対）

問題49:
The question box is for any student. The poster says not to ( ) to write, because no name is required on the paper.

選択肢49:
1. refuse
2. forget
3. hesitate
4. offer

【正解49】
3. hesitate

【解説49】
no name is required が、書きやすくする理由です。ためらわずに書いてほしい、というポスターです。hesitate to write は「書くのをためらう」で、not to hesitate は「遠慮しないで」です。
1 refuse to write は「書くのを拒む」で、名前が不要なこととはつながりが弱いです。2 forget to write は「書き忘れる」で、箱の招待にはなりません。4 offer to write は「書くと申し出る」で、not to offer だと書くな、という逆の指示になります。

【ポイント49】
種別: 単語
見出し: not hesitate to = 「遠慮しないで〜する」
・ためらいを消す情報 ← no name is required
・not to offer → 「するな」（not hesitate to とは逆）
・to write を伴う動詞かを見る

問題50:
The form says students must apply by themselves. ( ), a parent cannot send the form for them.

選択肢50:
1. In the past
2. In a moment
3. In no time
4. In other words

【正解50】
4. In other words

【解説50】
自分で申し込まなければならない、と、保護者が代わりに用紙を送れない、は同じ規則の言い換えです。in other words は「言い換えると」です。
1 In the past は「過去には」で、今の規則の説明にはなりません。2 In a moment は「すぐに」です。3 In no time も「すぐ」で、must の内容を言い換えてはいません。

【ポイント50】
種別: 熟語
見出し: in other words = 「言い換えると」
・同じ意味の言いかえ ← must apply by themselves と cannot send for them
・in a moment / in no time = 「すぐに」（時間の短さ）
・言い換えの文は、新しい条件を足さない
